# 独立验证链 —— 结果汇总

四个脚本（其中三个已修），全部在本地跑通。每个脚本用不同的随机种子和独立参数化。

## 1  `independent_check_fixed.py`  →  120+126 的秩与非線性

| 项目 | 结果 |
|---|---|
| 秩普查（300 点，22 参数，seed 999983） | 300/300 均为 **12** |
| 左零空间漂移 `std/|mean|` | md1 1.74，me1 2.92，`|Vub|` 8.28，**J 178.3** |
| 线性拟合的相对波动 | **2.851** → 不存在常系数线性关系 |

结论：rank 12 由独立参数化复现；关系是非线性的，因此不存在紧凑多项式形式。

## 5  已修的三处

1. `d5_theorems` STEP 5 的恒等式写错：`tr H_e = 5 tr H_d + 4(P+Q)` 右端展开为 `9P+9Q`，
   左端为 `9P+Q`，相差 `8Q`，故误差 2.7 而脚本仍打印"关系成立"。已替换为定理 C 的正确形式，
   并把 print 改成 assert。
2. `d5_theorems` STEP 4 检验的是推论 C（几乎恒真），与论文的推论 D 不是一回事。已替换。
3. `independent_check2` Part 3 把 Yukawa 与 vev 同时取实，得到 8；已改为复 Yukawa + 实 vev，
   得到 11。
4. `independent_check` 的 docstring 承诺三部分但只实现第一部分；已改写。死代码已删。
